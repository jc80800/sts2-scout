# Offline English OCR

`eng.traineddata` is from https://github.com/tesseract-ocr/tessdata_best/blob/main/eng.traineddata, retrieved 2026-09-06. Apache License 2.0 is reproduced in LICENSE. The model is generic English, not trained on game screenshots or card slots. Refresh deliberately and rerun native OCR fixtures. The runtime has no download path. Model hashes are checked by `scripts/check_ocr_model.py`.
